安装状态改变时，用户到底要决定什么？

这个原型检查 ai-cli-manager 在“全部未安装、部分安装、全部安装、版本不可读”四类状态下， 应显示哪些动作；同时比较当前的“每个工具一个推荐入口”和实验性的“允许选择来源”会带来多少额外决策。

当前生产行为是“唯一推荐入口”，不提供来源选择。右侧可切到“实验：选择来源”仅用于比较， 不代表已决定修改生产设计。
